# Installation Requests & UI Updates Summary

Date: 2026-01-24

Summary of changes and fixes applied during the recent work on installation requests, appointments, orders, and admin UI.

- Restored visibility of section titles in Ocular and Installation admin pages.
- Fixed view/details layout in the Orders page and Order Overview section.
- Fixed system alert boxes (replaced blocking alerts with non-blocking popups where requested).
 - Implemented non-blocking calendar day popup to list orders instead of blocking alerts.
 - Hid "Link to Order" for ocular appointments in the appointment modal.
 - Replaced external CDN social icons with local SVG assets (with fallback text) in footer.
 - Added export endpoints and printable fallback (Excel/PDF/Print) for orders/exports.
 - Fixed `booking_complete.php` parse errors and rewrote booking/order-complete layout and invoice logic.
- Implemented customer "Request Installation Date Change" flow:
  - Customers can request an installation date change (within 7 days) from Track Order / Notifications UI.
  - `ShopCon::request_installation_date_change()` updates the installation appointment immediately, writes an activity log entry, and emails active admins.
- Admin Requests tab (Installation page):
  - New endpoint `AdminCon::get_installation_date_change_requests()` returns parsed and enriched rows from `system_activity_log` (order, client, appointment, specs, staff, status).
  - Admin UI (`assets/js/admin-js/appointment-management.js`) renders a Requests table showing: Requested Date, Client, Order (link), Date & Time, Specs, Assigned Staff, Status, Actions.
- Fabrication automation & UI:
  - Controller auto-sets `FabricationStartDate` and `FabricationEndDate` when status transitions to "In Progress" (Direct: +5 days; Site-Assessed: +15 days).
  - Removed Actual Start/End inputs from the production modal (dates now managed server-side).
- Notifications:
  - `application/helpers/notification_helper.php` now attempts best-effort HTML email sends to customers when notifications are created.
- Navigation & housekeeping:
  - Removed "Return Orders" menu item from admin sidebar and `AdminCon::admin_return_orders()` now redirects to `admin-orders`.
