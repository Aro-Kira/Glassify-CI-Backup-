## 8. DATABASE MAPPING SUGGESTIONS

Based on the existing customization fields in the system, here's how these options map:

- **Dimensions** → All products (Width × Height, and depth for cabinets)
- **GlassShape** → Windows, Doors, Mirrors (Round, Oval, Rectangle, Arched, Custom)
- **GlassType** → Windows, Doors, Shower enclosures, Mirrors, Cabinet doors
- **GlassThickness** → All glass products
- **EdgeWork** → Mirrors (Beveled, Polished, Pencil edge), Glass edges
- **FrameType** → All products (Material, Style, Profile)
- **Engraving** → Custom text/designs on products
- **DesignRef** → Reference to design files, images
- **LEDBacklight** → LED mirrors, Cabinet lighting
- **DoorOperation** → Doors, Windows (Swing, Sliding, Hanging, Fixed)
- **Configuration** → Panel arrangements, Layouts, Mounting methods
- **EstimatePrice** → All products
- **PriceBreakdown** → All products (JSON with price components)

### Additional Fields to Consider:
- **FrameColor** → Separate field for frame color selection
- **HardwareFinish** → Hardware color/finish selection
- **MeshType** → For screen doors (Ordinary, Hardmesh)
- **PanelCount** → Number of panels/doors
- **Series** → Product series (e.g., "900 Series", "798 Series", "38 Series")
- **GridPattern** → Grid style for French type products
- **InternalOrganizers** → JSON field for cabinet organizer selections
