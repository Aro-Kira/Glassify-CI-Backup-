# Glassify-CI Changes Summary

## What Was Added & Changed

### 🖼️ **Product Image Rules Changed**
- **Before**: Had to upload at least 3 images per product
- **Now**: Can upload 1-10 images per product (more flexible)

### 🏪 **Admin Product Management Improved**
- Admin can now see ALL products (even out of stock ones)
- Customers still only see available products
- Better inventory tracking based on materials

### 🪟 **Sliding Windows Customization - MAJOR UPGRADE**
**New 4-Step Customization Process:**

**Step 1 - Basic Setup:**
- Choose: 2 Panels or 4 Panels
- Transom options: None, Fixed Top Panel, or Fixed Bottom Panel

**Step 2 - Track & Panel Setup:**
- Track System: 2 Tracks or 3 Tracks
- Panel Configuration: Various sliding/fixed combinations

**Step 3 - Materials:**
- Frame Colors: Hanalok, White, Black, Gray, Wood Finish
- Glass Types: 17 options including Clear, Ultra Clear, Bronze, Reflective types, Tempered glass
- Glass Thickness: 6mm

**Step 4 - Hardware:**
- Lock Types: 4 different lock options
- Roller Types: 3 roller configurations
- Screen: With screen or Without screen

### 🖼️ **New Images Added**
- **8 Design Images**: For 2D modeling features
- **11 Product Images**: New products added to catalog

### 💾 **Database Updates**
- New script to save all the sliding window customization options
- Safe updates that won't break existing data

## Simple Summary

**Main Changes:**
